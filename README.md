# 광명 상권길잡이 (비공식)

공공데이터로 보는 광명시 19개 행정동의 상권·인구 현황 사이트입니다. 설치 없이 `index.html` 한 파일로 동작합니다.

**바로 보기:** https://charlychae7-lang.github.io/gwangmyeong-sangkwon-guide/

## 꼭 읽어 주세요

- 이 사이트는 개인이 만든 **비공식** 사이트입니다. 소상공인시장진흥공단, 소상공인365, 행정안전부, 광명시와 **관련이 없으며** 이들이 운영·후원·보증하지 않습니다.
- 수치는 **참고용**입니다. 창업·대출·계약 같은 중요한 판단 전에는 반드시 소상공인365(https://bigdata.sbiz.or.kr)와 광명시 등 **공식 자료를 확인**하세요.
- '인구 1천명당 업소 수', 'LQ', '인구밀도' 등은 아래 자료로 이 사이트가 계산한 값이며 공식 통계가 아닙니다.
- 매출, 유동인구, 개폐업률 등 공공데이터로 확인되지 않은 항목은 싣지 않았고 '공공데이터 미제공'으로 표시했습니다.

## 사용한 자료와 출처

| 자료 | 제공 기관 | 기준 |
|---|---|---|
| 상가(상권)정보 (동별·업종별 업소 수) | 소상공인시장진흥공단, 공공데이터포털 | 2026.09 |
| 주민등록 인구 및 세대현황, 행정동별 성/연령별 인구 | 행정안전부, 공공데이터포털 | 2026.10 |
| 행정동 경계 | 통계청(현 국가데이터처) 통계지리정보서비스(SGIS) 행정동 경계, 공공누리 제1유형(출처표시). 보정본: [vuski/admdongkor](https://github.com/vuski/admdongkor) (CC BY 4.0). 이 사이트가 도형을 단순화함 | 2025.04 |

## 개인정보

회원가입이 없고 개인정보를 수집하지 않습니다. 입력한 값은 브라우저 안에서만 계산되며 서버로 전송·저장되지 않습니다.

## 보는 방법

1. 위 '바로 보기' 주소를 누르면 됩니다.
2. 내려받아 보려면 `index.html`을 내려받아 더블클릭하면 브라우저에서 열립니다.
